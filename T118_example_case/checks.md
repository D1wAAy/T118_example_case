# Результаты проверок

Каждая проверка выполнялась на свежем списке из трёх исходных записей.

## cases.py
1. `add_case(items, "Новый тест")`: ожидалось 8, получено 8.
2. `add_case(items, "     ")`: ожидалось None, получено None. `len(items)` = 3, список не изменился.
3. `add_case(items, "abcd")` (4 символа): ожидалось None, получено None.
4. `add_case(items, "abcde")` (5 символов): ожидалось 8, получено 8.
5. `add_case([], "abcde")`: ожидалось 1, получено 1.
6. `valid_cases([])`: ожидалось True, получено True.
7. `valid_cases` с повтором ID: ожидалось False, получено False.
8. `valid_cases` с `id=True`: ожидалось False, получено False.
9. `valid_cases` с названием из 4 символов, из пробелов, не строкой и с неверным статусом: ожидалось False, получено False.
10. `valid_cases` с названием из 5 символов и статусом `pass`: ожидалось True, получено True.
11. `set_result(items, 1, " PASS ")`: ожидалось updated, получено updated.
12. `set_result(items, 4, "pass")`: ожидалось unchanged, получено unchanged.
13. `set_result(items, 99, "fail")`: ожидалось not_found, получено not_found.
14. `set_result(items, 99, "bad")`: ожидалось invalid_status, получено invalid_status.
15. `summarize(items)`: ожидалось `{'total': 3, 'pending': 1, 'pass': 1, 'fail': 1}`, получено то же.
16. `summarize([])`: ожидалось `{'total': 0, 'pending': 0, 'pass': 0, 'fail': 0}`, получено то же.

## storage.py
1. Сохранить три исходные записи и загрузить: ожидалось, что результат равен исходному списку, получено True.
2. Сохранить `[]` и загрузить: ожидалось `[]`, получено `[]`.
3. Загрузить несуществующий файл: ожидалось `[]`, получено `[]`.
4. Загрузить пустой файл: ожидалось None, получено None.
5. Загрузить файл с текстом `{bad`: ожидалось None, получено None.
6. Загрузить файл с JSON `{}`: ожидалось None, получено None.
7. Сохранить некорректный список `[1, 2]` в существующий файл: ожидалось False, получено False. Файл остался прежним.
8. `import storage`: `cases.json` не создаётся, сообщений нет.

## main.py
1. Запуск без `cases.json`: журнал пуст, меню работает.
2. Запуск с повреждённым `cases.json`: сообщение об ошибке, выход без записи.
3. Ввод ID `abc`, `1.5`, `0`, `-5`: программа не падает, выводит ошибку.
4. Выход, ответ `да`: сохранение и выход. После нового запуска запись на месте.
5. Выход, ответ `нет`: выход без записи.
6. Выход, ответ `maybe`: остаёмся в меню.
7. `import main`: меню и ввод не появляются, файлы не создаются.
