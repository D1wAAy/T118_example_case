# Т118: журнал тестовых проверок
Файлы: cases.py (логика), storage.py (JSON), main.py (меню), example-cases.json (пример данных), checks.md (проверки).

## Запуск
Из папки проекта:
python main.py

Данные берутся из cases.json. Нет файла: журнал пуст. Файл повреждён: ошибка и выход без записи.

## Меню
1 список, 2 добавить, 3 результат, 4 сводка, 5 сохранить, 0 выход (с вопросом «Сохранить? да/нет»).
